Python Programs - Questions 25 to 34

This folder contains 10 separate Python programs.

How to run:
1. Extract the ZIP file.
2. Open the folder in VS Code.
3. Open a .py file.
4. Run it using the Run button, or in the terminal:
   python filename.py
